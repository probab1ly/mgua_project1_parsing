# Настройка рассылки через Яндекс.Почту

Приложение отправляет письмо после каждого завершённого обновления данных:

- если появились новые материалы — отправляет только новые материалы с кратким описанием и ссылками;
- если новых материалов нет — отправляет сообщение, что проверка выполнена, но новых материалов не найдено.

## 1. Что нужно от Яндекса

Нужен не обычный пароль от аккаунта, а отдельный пароль приложения для Почты.

Официальные параметры Яндекса для исходящей почты:

- SMTP-сервер: `smtp.yandex.ru`;
- защита соединения: `SSL`;
- порт: `465`;
- если используется STARTTLS вместо SSL: порт `587`;
- логин: ваш полный адрес Яндекс.Почты, например `example@yandex.ru`;
- пароль: пароль приложения для Почты.

## 2. Как получить пароль приложения

1. Войдите в Яндекс ID.
2. Откройте раздел управления паролями приложений.
3. Создайте новый пароль приложения.
4. Тип приложения выберите `Почта`.
5. Название можно указать `AI Regulation Monitor`.
6. Скопируйте пароль сразу: Яндекс показывает его только один раз.

## 3. Что вписать в `email_config.json`

Файл уже подготовлен под Яндекс:

```json
{
  "enabled": true,
  "smtp_host": "smtp.yandex.ru",
  "smtp_port": 465,
  "smtp_username": "your-login@yandex.ru",
  "from_email": "your-login@yandex.ru",
  "use_tls": false,
  "use_ssl": true,
  "timeout": 90,
  "recipients": [
    "nikisindimon653@gmail.com"
  ]
}
```

Замените:

- `your-login@yandex.ru` на вашу настоящую Яндекс.Почту;
- список `recipients` на адреса получателей.

Пароль в этот файл не вставляйте.

## 4. Что вписать в `.env`

Создайте или откройте файл `.env` рядом с `app.py`:

```env
AI_MONITOR_SMTP_PASSWORD=ваш-пароль-приложения-яндекс-почты
```

Можно также продублировать полный SMTP-набор:

```env
AI_MONITOR_SMTP_HOST=smtp.yandex.ru
AI_MONITOR_SMTP_PORT=465
AI_MONITOR_SMTP_USERNAME=your-login@yandex.ru
AI_MONITOR_SMTP_PASSWORD=ваш-пароль-приложения-яндекс-почты
AI_MONITOR_FROM_EMAIL=your-login@yandex.ru
AI_MONITOR_SMTP_TIMEOUT=90
```

На хостинге эти же значения нужно добавить в разделе `Environment Variables`, `Secrets`, `Config Vars` или похожем.

## 5. Как проверить отправку

Запустите:

```powershell
python quality_assurance\tools\smtp_test.py
```

Если всё правильно, вы увидите:

```text
OK: тестовое письмо успешно отправлено
```

Если будет timeout или SSL-ошибка:

- проверьте, что порт `465`;
- проверьте, что `use_ssl=true`;
- попробуйте другую сеть;
- проверьте firewall/антивирус;
- убедитесь, что создан именно пароль приложения для Почты.

## 6. Как проверить в интерфейсе

1. Запустите приложение.
2. Войдите в аккаунт.
3. Откройте вкладку `История обновлений`.
4. Посмотрите блок email-статуса.
5. Если всё заполнено, `/api/email/status` должен показывать `ready=true`.

## 7. Важное про безопасность

- `.env` нельзя выкладывать на GitHub.
- Пароль приложения нельзя отправлять в чат и вставлять в `email_config.json`.
- Если пароль приложения случайно попал в GitHub, удалите его в Яндекс ID и создайте новый.
